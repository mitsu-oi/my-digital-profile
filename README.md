# ОсьЯ — мій цифровий профіль

Конструктор портфоліо, оформленого як офіційний документ. Людина без навичок дизайну за 10–15 хвилин
збирає профіль у вигляді «цифрового посвідчення»: обирає бланк і палітру, заповнює розділи, одразу бачить
результат і забирає його файлом PDF або HTML. Без реєстрації, безкоштовно, дані не залишають браузер.

**Сайт:** https://my-digital-profile-blond.vercel.app/

Підсумкова самостійна робота з курсу «Технології веброзробки та дизайну», варіант 3
(«Платформа портфоліо з інтерактивним конструктором»). Авторка — Дарія Батинчук.

## Можливості

- **Конструктор** (`builder.html`):
  - 4 бланки («Посвідчення», «Резюме», «Досьє», «Візитка») і 6 палітр;
  - розділи: про мене, навички, проєкти, досвід, освіта, досягнення, контакти;
  - живий перегляд на телефоні, планшеті й комп’ютері;
  - кожен бланк сам додає свої обов’язкові розділи;
  - порядок розділів змінюється перетягуванням, клавішами ↑ ↓ або меню;
  - лічильник заповненості з підказками й печаткою «Перевірено» на 100 %;
  - чернетка автоматично зберігається в `localStorage`;
  - експорт у PDF і самодостатній HTML-файл без реклами, який можна знову відкрити в конструкторі.
- **Головна:**
  - жива демонстрація: «паспорт» змінюється, поки ви пишете ім’я та фах;
  - стос прикладів, який гортають пальцем, мишею, кнопками або клавішами ← →;
  - віяло з чотирьох бланків.
- **Шаблони і Приклади:** каталог бланків і шість готових профілів з фільтрами. Будь-який бланк чи приклад
  відкривається в конструкторі одним натисканням.
- **Контакти:** форма з перевіркою RegEx (ім’я, email, телефон із маскою `+380 (XX) XXX-XX-XX`), зведенням
  помилок і модальним вікном. Навчальний проєкт: форма нічого не надсилає, і на сторінці про це сказано.
- Темна й світла тема, вибір зберігається в `localStorage`. Сторінка 404 і повні Open Graph-метатеги.

## Технології

| Що | Чим |
|---|---|
| Розмітка | семантичний HTML5 (6 сторінок + 404), перевірено W3C Nu |
| Стилі | Tailwind CSS v4 (CLI), токени дизайну в `@theme`, темна тема через `dark:` |
| Логіка | чистий JavaScript (ES-модулі), без фреймворків |
| Дані | `data/data.json`, завантаження через `fetch` + `async/await` зі станом помилки «Спробувати ще» |
| Шрифти | Lora, Golos Text, JetBrains Mono — локальні woff2 з кирилицею |
| Зображення | власні SVG: гільйош, гравірований портрет, штампи, іконки; OG-картинка 1200×630; гравюри, створені генеративним ШІ (портрети вигаданих людей у прикладах, ілюстрації «Про сервіс» і 404, промпти в `docs/PROMPTS.md`), у WebP |
| Аналітика | Vercel Web Analytics (анонімні перегляди без cookies) |
| Хостинг і CI/CD | Vercel + GitHub Actions |

### Сторонні бібліотеки (CDN, фіксована версія й SRI)

| Бібліотека | Де | Навіщо |
|---|---|---|
| [SortableJS](https://sortablejs.github.io/Sortable/) 1.15.6 | конструктор | перетягування розділів |
| [Swiper](https://swiperjs.com/) 11.2.10 | головна | стос прикладів (ефект `cards`), гортання жестом і клавіатурою |

Обидві бібліотеки завантажуються лише тоді, коли потрібні. Якщо CDN недоступний, сайт працює без них:
розділи переставляються кнопками, а приклади гортаються звичайною прокруткою.

## Як запустити локально

Потрібен Node.js 22 або новіший.

```bash
npm install
npm run build   # ілюстрації, сторінки, CSS і папка dist/
npm run serve   # http://localhost:4173
```

Сторінки треба відкривати через сервер, а не подвійним кліком: `fetch` не читає `data.json` з диска.

| Команда | Що робить |
|---|---|
| `npm run build:pages` | збирає сторінки: спільні `<head>`, шапка й підвал + вміст із `src/pages/` |
| `npm run build:css` / `npm run watch:css` | Tailwind: `src/input.css` → `css/site.css` |
| `npm run build:art` | генерує SVG-ілюстрації (`scripts/make-art.js`) |
| `npm run build:og` | знімок OG-картинки з `src/og.html` (потрібен Edge або Chrome) |
| `npm run check` | перевірка перед деплоєм: синтаксис JS, data.json, посилання, SEO-теги, один `h1`, `alt` |

Кореневі `*.html` і `css/site.css` згенеровані: правити треба `src/pages/*.html`, `src/input.css` і
`scripts/build-pages.js`.

## Структура

```
src/pages/        вміст сторінок (без спільних частин)
src/input.css     Tailwind: токени, теми, компоненти
assets/js/        скрипти сторінок (ES-модулі)
  builder.js        конструктор
  render-profile.js малювання профілю в 4 бланках (лише textContent)
  export.js         експорт HTML і PDF
  home-stack.js     стос прикладів на Swiper
  contact.js        форма з RegEx-перевіркою
data/data.json    бланки, палітри, приклади, підказки навичок, запитання
scripts/          збірка сторінок, ілюстрацій, OG-картинки, dist/ і перевірка сайту
.github/workflows/deploy.yml   CI/CD
```

## CI/CD

Після кожного push у `main` GitHub Actions:

1. збирає сайт;
2. запускає `npm run check`;
3. перевіряє, що зібрані файли закомічені;
4. лише якщо все добре, деплоїть на Vercel через Vercel CLI.

Автодеплой самого Vercel вимкнено (`vercel.json`), а відвідувачам віддається тільки папка `dist/`.

## Безпека та приватність

- Дані користувача виводяться лише через `textContent`, без `innerHTML`.
- Посилання приймаються тільки з `http`/`https` (захист від `javascript:`).
- Фото — лише PNG, JPEG чи WebP до 5 МБ, зменшується в браузері.
- Імпортований файл розбирається `DOMParser` і ніколи не виконується. З нього береться тільки вкладений JSON,
  а кожне поле перевіряється за білим списком.
- Пошкоджена чернетка в `localStorage` не ламає сторінку.
- Скрипти з CDN підключаються з контрольною сумою SRI.
- Vercel додає заголовки безпеки (`nosniff`, `Referrer-Policy`, `X-Frame-Options`, `Permissions-Policy`).

## Доступність

- Усі функції доступні з клавіатури: у перетягування й гортання є альтернативи кнопками й клавішами.
- Видимий фокус, підписи всіх полів, помилки з `aria-describedby`, оголошення змін через `aria-live`.
- Контраст обох тем перевірено за WCAG AA.
- Анімації вимикаються при `prefers-reduced-motion`.
- Перевірено axe-core на всіх сторінках у світлій і темній темах.
